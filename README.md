# 冷藏果风味声明的多人盲评证据

`资料/演练.json` 保存本地合成的业务记录，不含个人信息及实际企业数据。各资料集的字段、单位和有效范围见[资料格式](资料格式.md)。需要 Python 3.11.2，仅使用标准库，从项目根目录运行。

查看资料包的记录数量：

```sh
python3 inspect_packet.py
```

## 可反复更新的感官比较

`sensory/` 把盲码解盲、同批重复样、跨场共享参照、品种/熟度、评分、失效记录接成一套带时点的比较系统，`sensory_cli.py` 是运营入口。所有判定都接受 `--as-of` 日期：失效记录只在 `known` 当日及以后生效，印签可以按签发时点重放。

```sh
# 完整报告（比较边、网络组件、漂移诊断、声明、印签历史、补评留样）
python3 sensory_cli.py report --as-of 2026-11-23 --out 感官比较报告.md

# 指定批次/窗口现在能写什么
python3 sensory_cli.py request L2 --as-of 2026-11-23

# 一张印签签发时的依据、后来是否缩窄、当前能否沿用
python3 sensory_cli.py label L1

# 下一次盲评为什么要带某些留样、候选场次能否同排
python3 sensory_cli.py sessions --as-of 2026-11-23

# 比较网络与每条边的差值区间
python3 sensory_cli.py network --as-of 2026-11-23
```

### 判定原则（实现位置）

- **只认真实可比的参照链**：比较边必须同场、同品种、同熟度、按同一评委配对，且有效评委数达到 `min_valid_panel`（`sensory/study.py`）。只同品种不同熟度的对照（R4 的 KX）被排除并保留排除原因；断开的组件之间不产生绝对差。
- **失效是时点相关且按场次隔离的**：R2 的 K1 失效只撤出 R2，R1 的 K1 仍有效；`known` 之前的判断看不到该失效。
- **区间三分类**（`sensory/claims.py`）：90% 配对 t 区间完全落在容许带内才支持“与原果口感相当”；触及边界是“未定”；完全在带外才是“超出容许”；缺证、断链、参照场次不足都是“证据不足”，不是不合格。多场次用逆方差固定效应合并，Cochran Q 检查异质性。
- **参照场次计数**：按不同有效场次计，同场重复码不算两场；`min_reference_sessions` 不达标时区间只能描述、不能支撑声明。
- **共同影响传播**：共享参照的跨场漂移（ANOVA）会作为警告挂到每个依赖它的批次上，各份区间不得被当成相互独立的证据重复使用（`sensory/diagnostics.py`）。
- **窗口不外推**：已评日龄只能为实测日或两端都有有效实测的中间范围作证。
- **通用声明**：标签请求承诺的每个货批 × 允许参照 × 整个窗口都有支撑才给通用声明；否则只给局部文字与适用范围，未评搭配写成证据不足。
- **印签历史**：已印未发的印签按签发日重放证据；新失效可迫使停用，仍有独立比较路径的印签继续有效。
- **补评规划**（`sensory/planning.py`）：每个列入参照单场至少耗 `sessions.servings` 份留样，`keep_until` 当日可用；同一份留样不能补两个场次，候选场次成套检查冲突，并要求新场次同时连接需要恢复的货批—锚搭配。

## 编译与测试

```sh
python3 -m compileall -q inspect_packet.py sensory sensory_cli.py tests
python3 -m unittest discover -s tests -v
```

原有 `tests/test_packet.py` 继续检查输入记录的引用和格式；新增测试覆盖统计函数、失效时点、网络断开、容许带分类、窗口覆盖、印签缩窄、漂移传播与留样冲突。
